# Image Licensing

Lisensi yang boleh auto-approved:

- CC0
- Public Domain
- CC BY 4.0
- CC BY-SA 4.0

Lisensi yang ditolak:

- All Rights Reserved
- CC BY-NC
- CC BY-ND
- CC BY-NC-SA
- CC BY-NC-ND
- GFDL-only
- editorial use only
- fair use
- unknown

Sumber yang tidak boleh dipakai:

- Google Images langsung
- Pinterest
- marketplace
- media sosial
- blog tanpa lisensi jelas
- agregator tanpa sumber asli

Gambar internet wajib memiliki source page, source file, kreator atau attribution text, license code, license URL, accessed date, checksum, dimensi, alt text, dan catatan perubahan.
