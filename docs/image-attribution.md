# Image Attribution

Atribusi media publik ditampilkan pada konteks pemakaian gambar, terutama halaman detail tanaman, halaman jalan, dan metadata katalog poster. Proyek tidak lagi memakai halaman indeks `/sumber-gambar` karena halaman tersebut tidak membantu alur pengunjung umum.

Setiap atribusi yang tersedia tetap memuat:

- judul media
- kreator atau attribution text
- lisensi
- link sumber
- link lisensi
- perubahan yang dilakukan

Atribusi tidak dimasukkan ke `alt` text. `alt` tetap menjelaskan isi gambar untuk aksesibilitas.

Halaman admin Media Library tetap menyimpan metadata lengkap, termasuk reviewer internal dan status pemeriksaan hak/privasi. Data internal tersebut tidak ditampilkan kepada pengunjung publik.
