# Image Attribution

Halaman publik `/sumber-gambar` menampilkan media published yang sudah approved. Halaman ini tidak menampilkan private original URL, signed URL, reviewer, atau secret path internal.

Setiap atribusi memuat:

- judul media
- kreator atau attribution text
- lisensi
- link sumber
- link lisensi
- perubahan yang dilakukan

Atribusi tidak dimasukkan ke `alt` text. `alt` tetap menjelaskan isi gambar untuk aksesibilitas.
